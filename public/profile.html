Fill-Assist Bookmarklet
Drag the button below to your bookmarks bar. On any job application page, click it to auto-fill your name, email, phone, LinkedIn, and portfolio URL into matching fields -- highlighted in green so you can see exactly what changed. Fields for salary, work authorization, or sponsorship are never guessed -- they're highlighted in amber for you to answer yourself, since a wrong answer there is the single most damaging mistake an auto-apply tool can make. Nothing is ever submitted automatically, and your resume file still has to be attached by you (browsers block scripts from filling file inputs, by design). Re-drag this link whenever you update your contact info above, since the data is baked into the link itself -- nothing is fetched from this app while you're on another site.
✋ Fill My Application
Drag this to your bookmarks bar -- don't click it here.
Dragging not working? Copy the code and add it as a bookmark manually instead (steps below).
If drag-and-drop won't work in your browser:
1. Make sure the bookmarks bar is visible first (Chrome/Edge: Ctrl+Shift+B, Mac: Cmd+Shift+B).
2. Click "Copy the code" above.
3. Right-click your bookmarks bar → Add page... (or press Ctrl+D / Cmd+D on any tab to create a bookmark, then edit it).
4. Name it "Fill My Application", then paste the copied code into the URL/Location field (replacing whatever's there) and save.
5. Click that bookmark whenever you're on a job application page.
